# pbi-utils

面向 Windows 的 Power BI 辅助工具，用于查看和编辑模型、管理度量值、创建 PBIP 工程、生成示例数据，以及配置日期表、时间智能和 DAX UDF。提供中文与英文界面，也可通过命令行或本地 MCP 接入支持该协议的 AI 客户端。

[GitHub 下载](https://github.com/jiaopengzi/pbi-utils/releases) · [Gitee 下载](https://gitee.com/jiaopengzi/pbi-utils/releases) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/jiaopengzi/pbi-utils/issues)

## 下载与安装

当前分发面向 **Windows x64**。在发布页面选择 `v2` 开头的版本，请阅读对应发布说明。

1. 下载发布附件 `pbi-utils-<版本>-win-x64-without-dotnet.zip`，解压后运行其中的 `pbi-utils-<版本>-win-x64-without-dotnet-setup.exe`。
2. 按向导阅读许可、检查运行环境并选择安装位置。默认目录为 `%LOCALAPPDATA%\Programs\pbi-utils`。
3. 安装完成后，从桌面或开始菜单启动 pbi-utils。快捷方式可在安装时选择是否创建。

安装器会检查所需的 **x64 .NET Desktop Runtime** 和 **Microsoft Edge WebView2 Runtime**，缺失时提供安装入口。安装运行环境及注册 Power BI 外部工具时，可能需要 Windows 管理员授权。使用本软件无需安装开发 SDK、Node.js 或 pnpm；连接本地模型需要另行安装 Power BI Desktop。

安装完成后，重启 Power BI Desktop，即可在“外部工具”中使用 **pbi-utils** 打开并连接当前报表的本地模型。也可以直接启动 pbi-utils，在连接页选择目标。

## 主要功能

| 功能 | 可以做什么 |
| --- | --- |
| 模型连接 | 打开本地 PBIP/PBIX，连接已运行的 Power BI Desktop，或只读连接 Power BI Service、SSAS / XMLA |
| 度量值 | 查看、搜索、新增、编辑、删除和批量修改；在本地格式化 DAX |
| 表格模型 | 查看表、字段与存储统计，按需统计行数，将数据导出为 CSV 或 Excel |
| 模板度量值 | 管理可复用的度量配置，选择 TMDL 常量或 Config 文件模式 |
| 日期与时间智能 | 按需选择日期字段、农历、工作日和期间指标，预览生成的代码 |
| DAX UDF | 浏览与导入函数包、选择精确版本、管理本地函数，检查未使用函数 |
| 新建 PBIP | 从内置空白模板或自定义模板创建工程，组合模拟数据、度量值、日期与 UDF |
| 示例数据 | 生成零售业务示例数据，查看统计并追加新的日期区间 |
| 学习与设置 | 访问学习页面，切换界面语言、DAX 格式偏好，管理日志、更新与 MCP 连接 |

## 连接模型并开始使用

### 本地 Power BI Desktop

在“连接 → Power BI Desktop”中，选择已打开的实例，或选择 `.pbip` / `.pbix` 文件。文件入口会打开 Power BI Desktop，等待模型就绪后连接；同一文件已经打开时会尝试复用该实例。连接成功后进入模型页。

**在 pbi-utils 应用模型修改后，请到 Power BI Desktop 保存报表文件。** 模型提交成功与 PBIP/PBIX 文件保存是两件事。日期表等数据定义改变后，还需在 Desktop 中刷新相应表；pbi-utils 不自动刷新业务数据源。

每个窗口只有一个当前模型。可通过顶栏刷新或断开，再到连接页切换目标。取消文件打开的等待不会关闭已经启动的 Power BI Desktop 窗口。

pbi-utils 读取 Desktop 中的在线语义模型，不直接解包或改写 PBIX，也不编辑在线报表的视觉对象布局。仅实时连接云端语义模型、没有本地模型的报表，请改用 Power BI Service 入口连接原语义模型。

### Power BI Service 与 SSAS / XMLA

| 来源 | 连接方式 | 模型权限 |
| --- | --- | --- |
| Power BI Desktop | 已打开实例，或本地 PBIP/PBIX 文件 | 支持本地模型编辑 |
| Power BI Service | 工作或学校账号登录后选择工作区与语义模型；支持全球版和世纪互联 | 只读 |
| SSAS / XMLA | 填写服务器与数据库，按界面选择适用身份 | 只读 |

远端可读取的内容取决于账号权限、服务能力与租户设置；部分模型可能只提供有限的元数据。SSAS 可使用当前 Windows 身份或指定 Windows 账号，保存的密码不会回填到网页。Service 登录通过微软系统浏览器完成。

### 查看、编辑与导出

- **度量值**：单选查看和编辑，多选进行批量属性修改或格式化。DAX 格式化在本机完成，默认 Long，也可切换 Short；格式化后仍需保存才会提交修改。
- **表格模型**：查看字段和统计，勾选表后导出 CSV 或 Excel。默认每表抽样最多 100 行，也可调整上限或选择全部数据；Excel 将多张表写入同一工作簿的不同工作表。
- **模板度量值**：TMDL 模式将值直接写入度量定义；Config 模式使用工程中的 `pbi-utils/config.json`。显式应用配置会按名称创建或更新对应度量值，请先核对选择。

删除度量值时会检查模型内依赖，报表视觉对象中的引用仍需自行核查。只读来源不提供模型写入；统计和导出使用当前账号可见的数据。

## 新建工程与示例数据

在“新建”中选择内置 **blank** 或自定义模板，填写项目名和输出目录，再按需配置模拟数据、模板度量值、日期与时间智能、UDF。可选步骤不必全部启用，基础信息有效后即可创建。

创建成功后可打开工程目录，或点击“Power BI Desktop 打开”连接新模型。后续度量值、日期与 UDF 配置在“模型”中继续操作。

自定义模板通过新建页的模板管理入口维护，每个模板应包含一个完整 PBIP 及其本地报表、模型文件。新建工程的 PBIP 位于 `pbip/` 子目录；使用本地数据文件的工程整体移动后，需要在 Power Query 中更新 `PbiUtilsProjectRoot` 参数。

“示例”页可独立生成零售业务的 11 张 CSV 表及配套 PBIP，设置产品与门店数量、入库周期和日期范围；已有结果可追加新的日期区间。清空会删除固定示例 CSV 及整个配套 `pbip` 目录，包含自行放入该子目录的文件，执行前请核对。生成示例不会自动修改当前连接的模型。

## 日期、时间智能与 UDF

日期配置提供公历、农历、节日和工作日等字段，并支持导入工作日覆盖表。纯公历范围为 1900–2100 年，含农历字段时为 2000–2099 年；节日名称不等同于官方调休安排。可预览和复制生成的 Power Query M 函数及调用代码，时间智能则按所选期间和基础度量生成指标。

UDF 首次使用时，先选择来源并点击“更新来源”。内置来源为 DAXLib，也支持符合相同布局的 HTTP(S) Git 仓库及本地自定义函数。更新后，搜索、浏览、查看代码和选择版本使用本地缓存；只有显式更新来源才会下载函数库。

在模型页选好函数包后，点击“导入所选 UDF”；新建工程时则随工程一并导入。安装函数可能要求提升模型兼容级别，应用会检查目标是否支持并提示确认。函数定义导入成功不等于已经完成实际计算验证。

## 连接 AI 客户端（本地 MCP）

在“设置 → 本地 MCP”复制接入提示词，交给支持 **本地 stdio MCP** 的 AI 客户端。提示词包含当前安装路径、启动配置和验证步骤；复制本身不会修改客户端配置。pbi-utils 不内置聊天，也不管理 AI 密钥。

接入时请注意：

- 设置页推荐配置带有 `--allow-write`，允许客户端连接模型、生成文件和修改本地模型。手工启动 `pbi-utils.exe mcp serve` 时默认只读；省略该参数也会禁用连接切换等操作。
- 每个 MCP 客户端有自己的模型连接与登录状态，初始未连接，不自动沿用桌面窗口的当前模型。桌面和多个客户端可以同时运行。
- 即使启用写权限，Power BI Service 和 SSAS / XMLA 模型仍只读。修改本地模型后，报表文件仍需在 Power BI Desktop 保存。
- 设置页可查看与断开 MCP 连接，或“暂停接入”。暂停状态会保留，需主动恢复后客户端才能重新接入。

MCP 可用于模型读取与编辑、格式化、工程创建、示例数据、日期和 UDF 等业务。本机通信不代表 AI 的后续处理也在本机：第三方客户端可能将工具返回的信息发送给其模型提供方，请按所用客户端的数据规则管理访问。

## 命令行

安装目录的 `app` 子目录中包含 `pbi-utils.exe`。可在该目录打开 PowerShell，执行：

```powershell
.\pbi-utils.exe --help
.\pbi-utils.exe doctor --json
.\pbi-utils.exe inspect --project "D:\Reports\Sales.pbip" --json
.\pbi-utils.exe new templates --json
.\pbi-utils.exe updates check --source github --json
```

命令行还提供格式化、示例生成、新建工程、UDF 目录和副本变更等功能，参数以 `--help` 为准。`inspect` 读取本地 PBIP 工程；`change` 预览并应用到新目录副本，不覆盖源工程。

## 软件更新

在“设置 → 软件更新”选择 GitHub 或 Gitee，点击“检查更新”或“打开软件发布页面”。自动检查默认开启，每个来源最多每 24 小时自动检查一次。

更新列表同时识别正式版和预发布版。是否提示新版按产品数字版本比较，同一数字版本下的不同预发布轮次请到发布页面核对。应用不会自动下载、运行安装器或重启。

更新时，先断开 MCP 客户端并正常关闭 pbi-utils，再运行新版安装包。安装器支持升级和同版本修复，拒绝降级；卸载保留应用用户数据和共享运行环境。

## 常见问题与本地数据

**找不到当前报表模型？** 等待 Desktop 完成加载后刷新实例列表；如果报表仅实时连接 Service 且没有本地模型，请使用 Service 入口。无法连接的实例可查看具体原因。

**模型修改成功，为什么文件没有变化？** 请在 Power BI Desktop 保存。若提示执行结果待核验，应先检查实际模型状态并按提示重新读取，避免重复执行同一修改。

**UDF 列表为空？** 首次使用需要手动“更新来源”；后续更新失败时会保留原缓存。

**MCP 无法接入？** 检查客户端中的程序路径，以及“设置 → 本地 MCP”是否已暂停接入。重新配置后，在实际客户端中执行提示词里的验证步骤。

设置、最近记录、自定义模板、本地 UDF、缓存和日志位于 `%USERPROFILE%\.pbi-utils`。设置页可打开日志目录、查看运行环境，或重置全部本地数据。**重置会删除该目录中的自定义模板和本地函数等内容**，执行前请保留需要的文件；目录之外的 Power BI 工程不在重置范围内，重置也不会撤销已经提交的模型修改。

报告问题时，请附上应用版本、复现步骤和界面错误信息；提交模型或报表前请移除不宜公开的数据。
